SIL Open Font License 1.1 (see the `OFL-*.txt` files in this folder).

| -------------------------------------------------- | ---------------------------------------------------------- | -------------------------- |
| `inter-400.woff`, `inter-600.woff`                 | Inter, © The Inter Project Authors                         | `OFL-inter.txt`            |
| `space-grotesk-500.woff`, `space-grotesk-700.woff` | Space Grotesk, © The Space Grotesk Project Authors         | `OFL-spacegrotesk.txt`     |
| `libre-baskerville-*.woff`                         | Libre Baskerville, © The Libre Baskerville Project Authors | `OFL-librebaskerville.txt` |

The web interface uses the `@fontsource-variable` packages instead.
